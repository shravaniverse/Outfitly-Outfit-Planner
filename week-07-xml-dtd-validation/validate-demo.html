📋 DTD Validation Specification (outfits.dtd)

Practical 7: Demonstrating how Document Type Definitions ensure data integrity for Outfitly XML documents.

How DTD Links to XML:

In outfits.xml, the following document type declaration binds the schema:

<!DOCTYPE wardrobe SYSTEM "outfits.dtd">

DTD Rules Implemented:

Element / Attribute DTD Declaration Validation Meaning
wardrobe <!ELEMENT wardrobe (outfit+)> Root element must contain 1 or more outfit children.
outfit id id ID #REQUIRED Unique alphanumeric identifier required for every outfit.
category (Casual | Formal | Party | Winter | Athleisure) Enumeration: Category must be strictly one of these 5 permitted values.
accessories? accessories? Zero or one (optional) accessories section allowed inside pieces.
currency currency CDATA #FIXED "INR" Fixed attribute: must always equal "INR".
✅ Validation Status: The accompanying outfits.xml adheres strictly to these declarations and passes XML DTD validation checks.
