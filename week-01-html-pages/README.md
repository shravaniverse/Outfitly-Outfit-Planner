# Practical 1: HTML Static Home and Login Pages

## Aim
To design and develop static Home and Login web pages for the "Outfitly - Outfit Planner" web application using semantic HTML5 elements.

## Technologies Used
- HTML5 (HyperText Markup Language)

## File Descriptions
- `index.html`: The main landing page for Outfitly featuring a structured header, navigation bar, hero banner, "About Outfitly" description, wardrobe categories table, and a detailed "Look of the Day" showcase.
- `login.html`: A static user authentication form containing username/email, password, remember-me checkbox, submit button, and navigation links.

## Key HTML Elements Used
- Semantic containers: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- Layout & Tables: `<table>`, `<tr>`, `<td>` for structured presentation
- Headings & Text: `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<p>`, `<small>`, `<strong>`
- Forms & Controls: `<form>`, `<input type="text">`, `<input type="password">`, `<input type="checkbox">`, `<input type="submit">`, `<label>`
- Hyperlinks: `<a href="...">` for internal bookmarking and inter-page navigation

## How to Run
1. Navigate to the `week-01-html-pages/` folder.
2. Double-click `index.html` to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox).
3. Click the **Login** button on the top right navigation bar to view `login.html`.
4. Click **← Back to Home** to return.

## Expected Output
A well-structured, readable, and functional static website with working navigation between the Home page and the Login page.
