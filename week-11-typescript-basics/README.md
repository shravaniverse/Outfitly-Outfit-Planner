# Practical 11: TypeScript Classes, Interfaces, and Functions

## Aim
To model an object-oriented Wardrobe Management module using TypeScript, demonstrating type annotations, interfaces, classes with access modifiers (`public`, `private`, `readonly`), getters/setters, default and optional parameters, and generic functions.

## Technologies Used
- TypeScript 5.x
- Node.js runtime
- CommonJS module compilation

## Files Included
- `src/outfit.ts`: Comprehensive TypeScript source file containing interfaces, classes, typed functions, generics, and execution logic.
- `tsconfig.json`: TypeScript compiler options (`target: ES6`, `outDir: ./dist`, `strict: true`).
- `package.json`: NPM package metadata with compilation and execution scripts.
- `dist/outfit.js`: Compiled JavaScript output generated by `tsc`.
- `index.html`: Browser-based output viewer displaying results directly on screen.

## TypeScript Concepts Demonstrated
1. **Interfaces**:
   - `IClothingItem`: Enforces structure for individual garments with a `readonly id` and an optional `brand?: string`.
   - `IOutfit`: Defines contracts for outfit assemblages and price calculation methods.
   - `IStylistReview`: Standardizes feedback objects returned by stylist advisory functions.
2. **Classes & Encapsulation**:
   - `ClothingItem implements IClothingItem`: Uses `private _price` with `get price()` and `set price()` validation.
   - `Outfit implements IOutfit`: Manages item collections and handles percentage discount logic.
   - `WardrobeManager`: Aggregates outfits, calculates portfolio value, and filters by budget.
3. **Functions**:
   - Optional parameters: `calculateTotalPrice(discountPercent?: number)`.
   - Default parameters: `season: Season = "All-Season"`.
   - Generic function: `filterByProperty<T, K extends keyof T>(items: T[], key: K, value: T[K]): T[]`.

## How to Run

### Method 1: In Terminal using Node.js
```bash
# In the week-11-typescript-basics/ directory:
npx -p typescript tsc -p .   # Compiles src/outfit.ts into dist/outfit.js
node dist/outfit.js          # Executes the compiled JavaScript
```

### Method 2: In Web Browser
1. Open `index.html` directly in any browser.
2. The page renders the formatted terminal output directly on the screen.

## Expected Output
Console logs showing instantiated outfits, subtotal/discount calculations, budget filtering, and generic type filter outcomes.
